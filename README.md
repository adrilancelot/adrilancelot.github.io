==== Research ====

I work on untyped lambda-calculus and its variants, investigating operational and denotational semantics.

**Post Doc (U. Bologna):** some game semantics for now, and more to come on quantum computing

**PhD research:** program equivalences in call-by-value lambda-calculi, quantitative program equivalence, formalization of results on the $\lambda$-calculus

**What I wish to learn more of** : (operational) game semantics, models of the lambda-calculus, (verified) compilers, pi-calculus, realizability, fixed-points combinators, induction and coinduction, cyclic proofs ...
